# 测试指南

## 静态与模型检查

在仓库根目录运行：

```sh
npm ci --ignore-scripts
npm run check
npm test
npm run build
```

`npm test` 运行模型和生命周期测试，不启动 Zotero，也不读写文献库。

## 独立临时 Zotero 配置

仅使用独立临时配置，测试会创建、修改测试条目。生产 XPI 不含测试桥；测试脚本仅向 `/tmp/reading-status-live/profile` 的副本注入运行器。不要把此副本安装到日常 Zotero。

```sh
node scripts/live-profile.mjs tests/live.js
/Applications/Zotero.app/Contents/MacOS/zotero -purgecaches -no-remote -profile /tmp/reading-status-live/profile
```

测试配置与数据位于 `/tmp/reading-status-live/profile` 和 `/tmp/reading-status-live/data`。同步在测试配置中关闭。完成后报告写入 `/tmp/reading-status-live/report.json`，测试 Zotero 自行退出。

专项测试可替换第一条命令中的入口：

- `tests/late-selection-live.js`：延迟选择恢复与旧菜单/旧保存。
- `tests/gesture-repaint-live.js`：虚拟列表重绘期间的鼠标手势。
- `tests/settings-visual.js`：设置布局、主题选择、状态编辑及截图。
- `tests/reset-defaults-live.js`：真实确认/取消弹窗。
- `tests/sorted-selection-live.js`：升降序、PDF 父文献、选择和屏幕位置。
- `tests/harmonize-visual.js`：深浅色下的种子色偏色。

同一个测试配置应顺序运行，避免多个实例竞争。旧测试遗留的配置会影响重启验证；需要完全干净的测试时，先确认所有测试实例已退出，再另行准备临时目录。

## 可选主题兼容测试

先取得用于兼容检查的 主题 XPI，复制为 `/tmp/reading-status-live/theme-fixture.xpi`，然后在临时目录建立 `/tmp/reading-status-live/enable-theme-fixture` 文件，再运行完整测试。该文件仅选择测试分支；主题仅安装到临时配置。原始界面测试应移除这个标记。不自动下载或改动其他插件。

这些自动检查不是实体鼠标/触控板验证。人工验证时也必须使用临时配置，重点检查快速切换文献、状态排序、窄列、窗口边界和键盘操作。
