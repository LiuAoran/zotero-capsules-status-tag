# Zotero 10 接口核对

本项目以 macOS Zotero 10.0.6 的实际接口和源码核对为依据，结合 Zotero 官方插件文档。以下区分标准接口和有限内部适配；升级 Zotero 大版本时应重新核对。

## 自定义列与设置

使用 `Zotero.ItemTreeManager.registerColumn()` 注册独立列，`enabledTreeIDs` 为 `main`，使用 `dataProvider` 提供稳定排序键、`renderCell(index, data, column, isFirstColumn, document)` 创建胶囊。注册失败会中止启动，禁用时注销列。

宿主的函数包装不保留 `renderCell` 的 `this`，因此从传入文档的 `ZoteroPane.itemsView` 解析当前行，不依赖回调上下文或可能陈旧的列数据。排序键包含配置顺序及稳定文献 ID。

设置使用 `Zotero.PreferencePanes.register()`；偏好统一保存在 `extensions.readingStatusCapsules.*`。源码静态页面位于 `addon/content/`，打包后位于 XPI 的 `content/`。

## 标签、权限与事务

使用条目的 `getTags()`、`setTags()`、`isEditable()`、`deleted` 及 `saveTx()`。状态保存使用标准手动标签，`undoAction` 为 `undo-action-edit-metadata`，通过真实 Zotero 撤销/重做验证。

PDF 子条目经 `parentItemID` 解析普通父文献，保存也作用于父文献；独立附件和笔记不提供编辑。冲突标签只在用户主动选择时清理，不在读取或显示时写入。

## 有限内部适配

首次列位置使用实际视图的 `_getColumnPrefs()`、`_storeColumnPrefs()` 和列刷新接口；仅在没有该列偏好时初始化，后续保留用户调整。Zotero 10.0.6 未提供可替代的公开首次列位置接口。

读取 `_sortedColumn.dataKey` 判断当前状态排序；只有状态配置变化时发起一次合并的重新排序，普通标签保存交由宿主的 item-modify 通知排序。`invalidateRowCache(ids)` 按受影响文献 ID 清除缓存，直接更新相关可见胶囊；不在每次保存时清空整表缓存或额外重排。

通过真实宿主行、源文献 ID 和父文献 ID 验证绑定。虚拟列表可能复用节点或在鼠标按下后重绘，因此松开时重新验证当前节点的身份，禁止把旧行号当作文献身份。

菜单保存同时校验菜单实例、用户输入版本和操作序号；异步选择、焦点与滚动恢复使用同一归属检查。状态排序后的屏幕位置校正最多进行两个动画帧，不持续轮询。

短期选择保护处理宿主晚到的缓存选择恢复；主动用户输入立即结束保护。文档级监听、菜单监听与设置监听统一登记并清理，选择保护的观察器和计时器按所属操作释放。没有替换 Zotero 方法、修改其他插件代码或扫描整个文献库。

具体边界、自动检查与真实运行记录见 [验证说明](验证说明.md)。
