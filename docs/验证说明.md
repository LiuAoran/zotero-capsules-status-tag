GitHub 目录整理只改变静态资源的位置和构建/打包脚本；运行插件的逻辑沿用此前已验证的内部功能基线。历史报告保留原始测试版本标识，不将它们冒充 1.0.0 的重新运行结果。仓库采用 `addon/` 保存静态文件、`build/` 保存生成文件，安装包根目录结构仍符合 Zotero 要求。

保留原有短期选择保护：菜单打开、保存期间及保存后 600 毫秒，可纠正晚到的缓存选择。真实用户点击、列表导航、滚动、失焦或禁用取消保护；没有用户输入事件的程序选择在这段时间内可能被纠正。其他平台和全部实体输入情形仍需额外验证。

## 启动排序修复（1.0.1）
